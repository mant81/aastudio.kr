# AASTUDIO 사이트 기획

## 목적

AASTUDIO.KR을 세 스튜디오의 상위 브랜드 사이트로 구성합니다. 제품 소개에서 무료 웹 도구 사용과 AA Studio Free 다운로드로 이어지는 진입점을 제공합니다.

기존 `aastudio.kr`과 유사한 기능을 새로 개발하고 있다는 사용자 설명을 바탕으로 기획했습니다. 기존 사이트의 문구·기능·이미지를 직접 확인하거나 복제한 상태는 아닙니다.

## 브랜드 체계

| 표시 이름 | 분야·의미 | 사이트에서의 역할 |
| --- | --- | --- |
| AASTUDIO | 상위 브랜드 | 세 스튜디오를 연결하는 공식 사이트 |
| AA Studio | Architecture | 설계·구조 시각화, 무료 버전 다운로드 안내 |
| AI Studio | Artificial Intelligence | AI 서비스·솔루션 소개 |
| ASF Studio | AI Smart Factory | QMS 등 제조·품질 관리 솔루션 소개 |

세 브랜드가 A로 시작하는 구성을 **Triple A** 콘셉트로 사용합니다. ASF는 AI Smart Factory의 약자입니다. AA Studio의 분야는 Architecture로 설명하되 제품명은 AA Studio를 사용합니다.

## 디자인 방향

사용자는 템플릿 같은 인상을 원하지 않습니다. 동일한 제품 카드나 상투적인 기능 목록보다는 브랜드의 이름, 여백, 타이포그래피와 각 분야의 그래픽을 중심으로 구성합니다.

- 크림색 배경과 짙은 올리브색 글자, 오렌지색 포인트.
- 큰 영문 타이포그래피와 짧은 한국어 설명.
- AA Studio는 구조 도면, AI Studio는 연결과 가능성, ASF Studio는 공정·품질을 표현한 그래픽.
- 세 브랜드를 독립된 가로 섹션으로 배치하고, 모바일에서는 세로로 재구성.
- 외부 이미지 없이 CSS와 SVG로 그래픽 구현.

현재 영문 헤드라인과 한국어 제품 설명은 사이트용으로 새로 작성한 제안 문구입니다. 사용자가 제공한 기존 공식 카피로 간주하지 않습니다. 로고타입의 ® 표시는 시각 초안이며 상표 등록 여부는 확인하지 않았으므로 공개 전 유지 여부를 확인해야 합니다.

## 모션과 연락처

2026-10-17에 반영한 로컬 구현입니다. CSS와 SVG를 사용하며, 별도 영상·이미지 파일이나 애니메이션 라이브러리는 필요하지 않습니다.

| 영역 | 동작 | 계속 유지하는 요소 |
| --- | --- | --- |
| 메인 제목 | 첫 줄 등장, `possibilities.`의 글자별 등장과 오렌지 파동, 곡선 밑줄 등장, 별표 회전. 글자 파동은 6.8초 주기 | 문구와 두 줄 구성 |
| Triple A 지도 | 궤도 등장, 신호 순환, 연결점 강조, 중앙 별표 회전 | 세 스튜디오의 이름과 연결 구조 |
| AA / `.blueprint` | 윗면 → 양쪽 면 → 내부 격자 순서로 컬러 선을 그린 뒤 잠시 유지하고 반복. 9초 주기 | 전체 도형·점선·연결점의 연한 회색 밑선. 반복 사이에도 도형이 사라지지 않음 |
| AI / `.intelligence-art` | 원형·타원형 궤도를 따라 오렌지 신호 순환, 연결점 강조, 중앙 `ai`의 색상·크기 반응과 별표 회전. 7초 주기 | 연한 회색 궤도와 `ai` 글자 |
| ASF / `.factory-art` | 공정 막대의 컬러 채움 → 품질 검사선 하강 → `Q`와 화살표 강조 → PROCESS에서 INSIGHT로 흐름 표현. 7초 주기 | 기본 막대, 구분선, `Q`와 문구 |

히어로 지도 위의 `MOTION ON/OFF` 버튼은 제목·지도와 세 스튜디오의 애니메이션을 함께 제어합니다. 스크롤로 화면에서 벗어난 영역과 비활성 탭의 모션은 자동으로 일시정지하며, 다시 보이면 재생합니다. 사용자가 버튼으로 정지한 상태는 자동 재생 조건과 별도로 유지됩니다. 새로고침하면 버튼 상태는 초기화됩니다.

`prefers-reduced-motion: reduce`에서는 모션을 끄고 정적인 그래픽을 표시하며 `MOTION` 버튼을 숨깁니다. JavaScript를 사용할 수 없어도 제목과 각 스튜디오의 기본 그래픽은 표시됩니다.

푸터의 `mant@nate.com`은 링크 없는 일반 텍스트입니다. `© 2026 AASTUDIO`와 같은 글꼴·크기·굵기·자간을 적용하며, 화면 너비에 따른 글자 크기 변경도 동일하게 따릅니다.

## 다운로드·도구 연동

AA Studio Free 배포 파일은 GitHub Releases를 통해 제공합니다. 현재 비공개 저장소는 **사이트 소스 저장소**이며, 다운로드 파일을 이 저장소의 비공개 Releases에 제공하는 것으로 가정하지 않습니다.

일반 방문자가 인증 없이 다운로드할 수 있도록 별도 공개 배포 저장소의 Releases 연결을 제안했습니다. 실제 저장소 이름과 운영체제별 파일 구성은 미정입니다. 현재 구현은 지정된 Releases 페이지로 이동하는 방식이며, GitHub API로 버전이나 설치 파일 목록을 자동 수집하지 않습니다.

도구 URL과 릴리스 URL이 비어 있으면 준비 중 상태를 유지합니다. 사이트 자체에 다이어그램 편집기·DB 모델링 기능이나 설치 파일이 포함된 것은 아닙니다.

## 구현·검증 현황

- 단일 정적 페이지와 PC·모바일 반응형 스타일 구현.
- 무료 도구 두 개와 다운로드 링크를 설정 파일에서 변경하도록 구현.
- HTTPS URL만 활성화하며, 미설정 링크는 준비 중으로 표시.
- JavaScript 문법 검사 통과.
- Chromium에서 1440px·390px 화면으로 페이지를 열어 HTTP 200, 가로 넘침 없음, 스튜디오 세 개 표시, JavaScript 오류 없음 확인.
- 테스트 URL을 주입해 도구·다운로드 링크 활성화 및 비 HTTPS 링크 차단 확인. 이는 실제 제품 URL에 대한 검증이 아닙니다.
- Google Fonts 요청을 차단한 조건에서도 시스템 글꼴로 렌더링 확인. 실제 Google Fonts 로드는 검증하지 않았습니다.
- 2026-10-17 모션 반영 후 Chromium에서 320·390·768·1440px 너비의 가로 넘침 없음과 JavaScript 오류 없음 확인. 히어로는 600·601·1000·1800px도 추가 확인.
- 히어로와 세 스튜디오의 애니메이션 진행, 기본 도형 유지, 화면 밖 자동 정지, `MOTION` 버튼의 전체 일시정지·재생 확인.
- AA 그래픽은 반복 시작·중간·완료·종료 시점 모두 회색 밑선과 연결점이 유지되는지 확인.
- 기기의 동작 줄이기 설정과 JavaScript 비활성 상태에서 정적 그래픽이 표시되는지 확인.
- PC·모바일에서 세 스튜디오 그래픽의 스크린샷을 확인. 스크린샷은 로컬 임시 검증 자료이며 저장소에는 포함하지 않음.
- 연락처는 일반 텍스트로 변경하고 저작권 문구와 공통 스타일을 사용하도록 수정. HTML 구조와 변경 파일의 공백 오류를 확인했으며, 이 수정 이후의 푸터 브라우저 검증은 수행하지 않음.

위 검증은 로컬 서버 기준입니다. 공개 도메인에서의 배포 검증 결과는 아닙니다.
