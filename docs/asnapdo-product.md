# ASnapdo 제품 페이지와 배포 파일

현재 공개용 버전: **1.0.3**. 제작사: **AAStudio.kr**. 개인·기업·관공서 모두 무료.

## 파일 구성

- `asnapdo/index.html`: 기능 설명 및 다운로드 안내.
- `asnapdo/product.js`: 실제 화면 확대 보기, 닫기와 초점 복원.
- `asnapdo/changelog/index.html`: 날짜와 버전별 변경이력. 1.0.3 개선 내역과 이전 1.0.2·1.0.1·1.0.0 이력을 함께 유지하며 미출시 버전은 기록하지 않음.
- `asnapdo/product.css`: 공통 사이트 스타일 위에 적용하는 ASnapdo 설명·변경이력 전용 레이아웃.
- `asnapdo/assets/`: 자체 SVG 아이콘과 실제 앱 화면. 앱 화면은 예시 캡처를 편집한 테스트 화면이며 콘셉트 이미지가 아님.
- `release/asnapdo_inst_x64_1.0.3.exe`: 실제 Windows x64 설치 패키지.
- `release/asnapdo-1.0.3.json`: 버전·날짜·다운로드 경로·파일 크기·SHA-256·설치 폴더 정보.
- `release/ASnapdo-LICENSE.txt`: 설치 화면 및 앱 도움말과 동일한 MIT 라이선스.

공통 Freeware 메뉴에서 `/freeware/` 목록으로 이동하고, ASnapdo 상세 페이지 또는 설치 파일을 선택합니다. 다운로드는 모든 페이지에서 GitHub Releases의 1.0.3 설치 파일로 연결되며 JavaScript 없이도 동작합니다. 외부 다운로드 링크에는 `download` 속성을 사용하지 않습니다. 전체 릴리즈는 [GitHub Releases](https://github.com/mant81/ASnapdo/releases/)에서 확인할 수 있습니다.

## 설치 패키지

파일명 규칙은 `asnapdo_inst_x64_<버전>.exe`입니다. 현재 파일은 `asnapdo_inst_x64_1.0.3.exe`이며 앱과 설치 프로그램 모두 1.0.3입니다. 기본 설치 폴더는 `C:\Program Files\ASnapdo`이고 설치 시 관리자 권한이 필요합니다. 로그인 자동 실행은 설치 시 기본 체크 상태이며 해제할 수 있습니다. 선택하면 원래 설치를 시작한 사용자의 HKCU에 등록됩니다. 설치 완료 후 실행 체크박스 없이 트레이에서 자동 실행합니다. 앱은 설치 후 일반 사용자 권한으로 실행하며 개인 설정과 편집 세션은 사용자별 데이터 폴더를 사용합니다.

## 배포

`.github/workflows/pages.yml`은 기존 정적 파일에 더해 `products/`·`freeware/`·`asnapdo/`·`release/`를 `_site/`로 복사합니다. 파일을 저장소에 커밋·업로드한 뒤 기존 Pages 워크플로가 성공해야 공개 주소의 페이지와 다운로드가 반영됩니다. 로컬 파일 생성 및 검증만으로 공개 배포가 완료된 것은 아닙니다.

업데이트할 때는 새 패키지를 `release/`에 추가하고 제품 설명·변경이력·Freeware 목록·JSON의 버전 및 링크를 함께 갱신합니다. 파일을 덮어썼다면 SHA-256과 크기를 다시 계산합니다.

## 검증

2026-11-01 사용성 개선: 활용 상황 세 가지에서 관련 기능으로 이동하고, 실제 앱 스크린샷 세 장을 확대해 볼 수 있습니다. 작은 화면에서는 원본 이미지도 새 탭으로 열 수 있습니다. 다운로드 버튼 옆에 무료 범위·Windows 지원·버전·파일 크기를 묶고, 설치와 업데이트 등 여섯 가지 FAQ를 추가했습니다. 기능 안내와 단축키 표는 항상 펼쳐 보이며, 기존의 제목 메뉴를 제거했습니다. FAQ 제목·분류와 두 열 배치로 문의 내용을 보기 쉽게 정리했습니다.

이미지 확대의 Escape·닫기 버튼·배경 클릭, 닫은 뒤 초점 복원, 키보드 FAQ 조작과 JavaScript 비활성 상태의 FAQ·원본 이미지 연결을 Chromium에서 검증했습니다. 기존 크림·올리브 색상, 직선 구분선, 제품 분류를 유지하며 자체 문구와 기존 ASnapdo 화면만 사용합니다. 외부 레퍼런스의 이미지·문구·코드를 포함하지 않습니다.

로컬 HTTP 서버에서 홈·설명·변경이력을 1440px, 900px, 390px 너비로 확인했습니다. 가로 넘침 없음, 내부 링크 및 이미지 정상, 브라우저 JavaScript 예외 없음. 브라우저에서 설치 파일을 실제 다운로드하여 파일명·크기·SHA-256이 릴리즈 메타데이터와 일치하는지 확인했습니다. GitHub Pages의 실제 공개 배포 및 공개 도메인에서의 다운로드 검증은 별도입니다.

## 1.0.3 반영 — 2026-11-02

최신 다운로드·변경이력·MIT 라이선스와 메타데이터를 갱신했습니다. PerMonitorV2 설정을 명시하며 코드 서명과 다중 DPI 수동 검증은 미완료입니다. 설치 파일은 36,575,041바이트, SHA-256은 `1ad2c14f939e9240317e0deb388dd9c020f41a2f00359bc5419082388ffd91bf`입니다. 이전 버전은 보존합니다.

## 1.0.2 반영

홈·제품 설명·변경이력과 최신 다운로드 정보를 1.0.2로 갱신했습니다. 영역 자동 복사와 클립보드 목록, 문맥별 도구 속성, 번호 크기 수정, 갤러리 닫기 및 제목 버전을 안내합니다. 이전 릴리즈 이력과 설치 파일은 보존합니다.

## 1.0.1 반영

트레이 캡처 전 창 깜빡임 수정, 선택 취소 시 트레이 복귀, 설치 후 자동 트레이 실행과 로그인 자동 실행 기본 체크를 반영했습니다. 보관 세션은 현재 Windows 계정으로 암호화합니다. 같은 계정 권한의 프로그램·클립보드·별도 PNG까지 보호하지는 않습니다. 공개 GitHub 릴리즈와 같은 SHA-256의 설치 파일을 로컬 release 폴더에 보관합니다. 디지털 서명 미적용 및 SmartScreen 경고 가능성도 제품 다운로드 안내에 명시합니다.
