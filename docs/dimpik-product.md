# DIMPIK 제품 페이지와 배포 파일

현재 공개용 버전: **1.0.5**. 제작사: **AAStudio.kr**. 개인·기업·관공서 모두 무료.

## 파일 구성

- `dimpik/index.html`: 기능 설명 및 다운로드 안내.
- `dimpik/product.js`: 실제 화면 확대 보기, 닫기와 초점 복원.
- `dimpik/changelog/index.html`: 날짜와 버전별 변경이력. 1.0.5 개선 내역과 이전 1.0.2·1.0.1·1.0.0 이력을 함께 유지하며 미출시 버전은 기록하지 않음.
- `dimpik/product.css`: 공통 사이트 스타일 위에 적용하는 DIMPIK 설명·변경이력 전용 레이아웃.
- `dimpik/assets/`: 자체 SVG 아이콘과 실제 앱 화면. 앱 화면은 예시 캡처를 편집한 테스트 화면이며 콘셉트 이미지가 아님.
- `release/dimpik_inst_x64_1.0.5.exe`: 실제 Windows x64 설치 패키지.
- `release/dimpik-1.0.5.json`: 버전·날짜·다운로드 경로·파일 크기·SHA-256·설치 폴더 정보.
- `release/DIMPIK-LICENSE.txt`: 설치 화면 및 앱 도움말과 동일한 MIT 라이선스.

공통 Freeware 메뉴에서 `/freeware/` 목록으로 이동하고, DIMPIK 상세 페이지 또는 설치 파일을 선택합니다. 다운로드는 모든 페이지에서 GitHub Releases의 1.0.5 설치 파일로 연결되며 JavaScript 없이도 동작합니다. 외부 다운로드 링크에는 `download` 속성을 사용하지 않습니다. 전체 릴리즈는 [GitHub Releases](https://github.com/mant81/DIMPIK/releases/)에서 확인할 수 있습니다.

## 설치 패키지

파일명 규칙은 `dimpik_inst_x64_<버전>.exe`입니다. 현재 파일은 `dimpik_inst_x64_1.0.5.exe`이며 앱과 설치 프로그램 모두 1.0.5입니다. 기본 설치 폴더는 `C:\Program Files\DIMPIK`이고 설치 시 관리자 권한이 필요합니다. 로그인 자동 실행은 설치 시 기본 체크 상태이며 해제할 수 있습니다. 선택하면 원래 설치를 시작한 사용자의 HKCU에 등록됩니다. 설치 완료 후 실행 체크박스 없이 트레이에서 자동 실행합니다. 앱은 설치 후 일반 사용자 권한으로 실행하며 개인 설정과 편집 세션은 사용자별 데이터 폴더를 사용합니다.

## 배포

`.github/workflows/pages.yml`은 기존 정적 파일에 더해 `products/`·`freeware/`·`dimpik/`·`release/`를 `_site/`로 복사합니다. 파일을 저장소에 커밋·업로드한 뒤 기존 Pages 워크플로가 성공해야 공개 주소의 페이지와 다운로드가 반영됩니다. 로컬 파일 생성 및 검증만으로 공개 배포가 완료된 것은 아닙니다.

업데이트할 때는 새 패키지를 `release/`에 추가하고 제품 설명·변경이력·Freeware 목록·JSON의 버전 및 링크를 함께 갱신합니다. 파일을 덮어썼다면 SHA-256과 크기를 다시 계산합니다.

## 검증

2026-11-01 사용성 개선: 활용 상황 세 가지에서 관련 기능으로 이동하고, 실제 앱 스크린샷 세 장을 확대해 볼 수 있습니다. 작은 화면에서는 원본 이미지도 새 탭으로 열 수 있습니다. 다운로드 버튼 옆에 무료 범위·Windows 지원·버전·파일 크기를 묶고, 설치와 업데이트 등 여섯 가지 FAQ를 추가했습니다. 기능 안내와 단축키 표는 항상 펼쳐 보이며, 기존의 제목 메뉴를 제거했습니다. FAQ 제목·분류와 두 열 배치로 문의 내용을 보기 쉽게 정리했습니다.

이미지 확대의 Escape·닫기 버튼·배경 클릭, 닫은 뒤 초점 복원, 키보드 FAQ 조작과 JavaScript 비활성 상태의 FAQ·원본 이미지 연결을 Chromium에서 검증했습니다. 기존 크림·올리브 색상, 직선 구분선, 제품 분류를 유지하며 자체 문구와 기존 DIMPIK 화면만 사용합니다. 외부 레퍼런스의 이미지·문구·코드를 포함하지 않습니다.

로컬 HTTP 서버에서 홈·설명·변경이력을 1440px, 900px, 390px 너비로 확인했습니다. 가로 넘침 없음, 내부 링크 및 이미지 정상, 브라우저 JavaScript 예외 없음. 브라우저에서 설치 파일을 실제 다운로드하여 파일명·크기·SHA-256이 릴리즈 메타데이터와 일치하는지 확인했습니다. GitHub Pages의 실제 공개 배포 및 공개 도메인에서의 다운로드 검증은 별도입니다.

## 1.0.5 반영 — 2026-11-11

최신 다운로드·변경이력·MIT 라이선스와 메타데이터를 갱신했습니다. PerMonitorV2 설정을 명시하며 코드 서명과 다중 DPI 수동 검증은 미완료입니다. 설치 파일은 36,575,041바이트, SHA-256은 `f2714e545841548707d3995aec1e9f68ee35f9aec2388fe508cec0bbaa5bcafa`입니다. 이전 버전은 보존합니다.

## 1.0.2 반영

홈·제품 설명·변경이력과 최신 다운로드 정보를 1.0.2로 갱신했습니다. 영역 자동 복사와 클립보드 목록, 문맥별 도구 속성, 번호 크기 수정, 갤러리 닫기 및 제목 버전을 안내합니다. 이전 릴리즈 이력과 설치 파일은 보존합니다.

설치 파일은 36,575,536바이트이며 공개 GitHub 릴리즈와 SHA-256 `5881ea9dfbb06adf1279fb49cbd143bb0b35f2cefc273eb346acd711ffe3a080`가 일치합니다. 검증 결과와 Pages 배포는 이번 변경 기준으로 별도 확인합니다.

## 1.0.1 반영

트레이 캡처 전 창 깜빡임 수정, 선택 취소 시 트레이 복귀, 설치 후 자동 트레이 실행과 로그인 자동 실행 기본 체크를 반영했습니다. 보관 세션은 현재 Windows 계정으로 암호화합니다. 같은 계정 권한의 프로그램·클립보드·별도 PNG까지 보호하지는 않습니다. 공개 GitHub 릴리즈와 같은 SHA-256의 설치 파일을 로컬 release 폴더에 보관합니다. 디지털 서명 미적용 및 SmartScreen 경고 가능성도 제품 다운로드 안내에 명시합니다.

1.0.1 로컬 브라우저 검증: 홈·제품 설명·변경이력을 1440px·900px·390px에서 확인했습니다. 가로 넘침·페이지 JavaScript 예외 없음, 내부 링크 15개와 이미지 정상, 최신 버전 링크 및 파일명·크기·SHA-256 표시 일치, 1.0.0 이력 보존과 변경이력 배치 확인. 설치 파일은 36,585,246바이트이며 SHA-256은 `7522ca6af28ae425da6f01a3f081e3dac20d7de129b859f87691bb4fd2e402a7`입니다.

## 2026-11-11 명칭 및 릴리즈 갱신

공개 표기를 DIMPIK(딤픽), 기본 경로를 `/dimpik/`로 변경했습니다. 제품 소개와 변경이력은 새 경로에서 제공합니다. 이전 주소의 리디렉션 폴더는 삭제했습니다. 최신 설치 파일은 1.0.5이며 GitHub Release와 동일한 SHA-256을 사용합니다. 이전 1.0.0~1.0.3 설치 파일은 웹 파일명만 변경했고 바이너리와 SHA-256은 유지했습니다. 이전 설치 경로는 해당 원본 설치 프로그램을 따르므로 역사 메타데이터의 설치 경로는 별도 안내로 남겼습니다. 실행 화면 이미지는 DIMPIK 1.0.5 기능 검사에서 생성한 실제 앱 화면이며 예시 캡처를 사용합니다.

검증: HTML 7개와 내부 링크/이미지 87개, 설치 파일 5개의 크기·SHA-256을 확인했습니다. 헤드리스 Edge에서 1440·900·390·320px의 홈·Freeware·제품 설명·변경이력 16개 화면에 가로 넘침/이미지 누락이 없었고, 이미지 미리보기 Escape 닫기·초점 복원 동작을 확인했습니다. JavaScript 예외는 0개였습니다.

설치 배포본의 편집기 DLL과 해시가 동일한 DIMPIK 1.0.5를 실행해 주석 편집, 모자이크·블러, 일반 설정 화면을 새로 캡처했습니다. 캔버스 내용은 기능 설명을 위한 예시 데이터입니다. 대표/효과 이미지는 1586×992, 일반 설정은 580×560이며 HTML 크기 속성도 맞췄습니다. 일반 설정에서는 설치 기본 상태의 자동 실행 체크와 갤러리 숨김을 표시하며 실제 사용자 레지스트리는 변경하지 않았습니다. 새 파일명에 버전을 포함해 이전 이미지 캐시를 피하고 캡션/대체 텍스트를 화면과 일치시켰습니다. 캡처 출처·크기·해시는 `dimpik/assets/screenshots-1.0.5.json`에 기록했습니다.

소개 페이지·변경이력·Freeware 목록과 홈의 제품명은 한글 `딤픽`을 우선 표시하고 영문 `DIMPIK`은 작은 보조 표기로 제공합니다. 제품 소개의 섹션 표제·링크·문서 제목도 한글 중심으로 정리했으며 다운로드 URL과 설치 파일 식별자는 변경하지 않았습니다.
