1.0.1 버그 수정 · 보안 개선

2026년 10월 31일

캡처와 설치

  • 트레이에서 캡처할 때 편집 창이 잠깐 나타나던 문제를 수정했습니다. 캡처 전에는 창을 숨기고 완료 후 결과를 표시합니다.
  • 영역 선택을 취소하면 편집 창을 열지 않고 트레이 대기로 돌아갑니다.
  • 설치 완료 후 실행 체크박스 없이 트레이에서 자동 실행합니다.
  • Windows 로그인 시 자동 실행을 설치 화면에서 기본 체크로 제공합니다. 설치 화면이나 설정에서 해제할 수 있습니다.

보안 개선

  • 원본·주석·실행 취소 이력을 포함한 보관 세션을 현재 Windows 계정으로 암호화합니다. 기존 평문 세션은 검증 후 자동 변환합니다.
  • 손상된 세션과 잘못된 값, 과도한 크기의 이미지·설정·편집 데이터를 거부하도록 검증을 강화했습니다.
  • 네이티브 트레이의 긴 경로 처리와 명령행 해석을 수정하고 스택 보호·CFG·DLL 검색 경로 보호를 적용했습니다.

기존 앱은 필요한 이미지를 저장하고 트레이에서 종료한 뒤 업데이트하세요. 암호화된 세션은 다른 계정·PC에서 복원되지 않을 수 있으며, 같은 계정 권한의 프로그램·클립보드·별도 PNG까지 보호하지는 않습니다. 현재 설치 파일은 미서명이며 SmartScreen 경고가 나타날 수 있습니다. 백신 검사는 미완료이고, 현재 환경의 대기 메모리는 약 11MB로 10MB 목표를 초과합니다.

1.0.0 최초 정식 릴리즈

2026년 10월 31일

캡처와 편집

  • 영역 캡처와 마우스가 있는 모니터의 전체 화면 캡처.
  • 영역 선택 시 크기·좌표·주변 픽셀 표시, Shift 정사각형 선택과 Esc 취소.
  • 여러 캡처를 독립 탭으로 관리하고 탭별 주석·실행 취소·확대 상태 유지.
  • 화살표·사각형·텍스트·번호·형광펜과 객체 이동·크기 조절·삭제.
  • 선택 영역 자르기, 픽셀 줄자, Ctrl+휠 확대·축소와 Ctrl+0 화면 맞춤.

효과와 복사

  • 모자이크·블러 영역 선택, 강도 조절, 미리보기와 실행 취소.
  • 편집한 전체 이미지 또는 선택 영역을 클립보드에 복사.
  • 다른 캡처 탭에 이미지와 주석을 붙여넣고 계속 편집.
  • 편집 결과 PNG 저장과 캡처 원본 자동 저장 폴더 설정.

설정과 실행 환경

  • 캡처·단축키·저장·일반으로 나눈 설정 화면.
  • 선택형 하단 캡처 갤러리와 썸네일을 통한 탭 전환.
  • Windows 로그인 시 자동 실행과 사용자별 캡처 단축키 설정.
  • 설정 창이 열려 있는 동안 캡처 실행 방지.
  • 네이티브 트레이 상주부와 EXE·DLL 편집기 분리. 창을 닫으면 편집 상태를 보관하고 편집기 프로세스 종료.

배포와 라이선스

  • Windows x64 설치 패키지 제공: asnapdo_inst_x64_1.0.0.exe.
  • 기본 설치 위치는 C:\Program Files\ASnapdo이며 설치 시 관리자 권한 필요.
  • 개인·기업·관공서 모두 무료. 제작사 AAStudio.kr.
  • 설치 과정에 무료 이용약관과 동의 단계 제공.

1.0.0에서는 자동 실행과 갤러리 표시가 기본 꺼짐이었습니다. 앱 내 자동 업데이트는 제공하지 않습니다. 새 버전을 설치하려면 필요한 이미지를 저장하고 트레이에서 앱을 종료한 뒤 새 설치 파일을 실행하세요.
